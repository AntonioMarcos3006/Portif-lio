## Sobre mim

Sou **Antonio Marques**, moro em Florianópolis (SC) e estou cursando o Ensino Médio junto com o técnico em **Desenvolvimento de Software no SENAI**. No curso aprendo desde lógica de programação até a criação de interfaces completas.
